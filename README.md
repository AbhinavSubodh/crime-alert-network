# Crime Alert Network

A comprehensive web-based platform for crime monitoring and reporting across Indian cities, featuring real-time mapping, crime reporting, and statistical analysis.

## Overview

The Crime Alert Network is a community-driven platform designed to enhance public safety through real-time crime monitoring and reporting. The system provides users with interactive crime mapping, detailed crime reporting capabilities, and comprehensive statistical analysis across 36 major Indian cities.

## Features

### Interactive Crime Mapping
- Real-time visualization of reported crimes
- Color-coded markers for different crime types
- Detailed location information and crime descriptions
- Custom map styling and controls
- Location-based filtering and search

### Crime Reporting System
- User-friendly crime report submission
- Interactive location selection via map
- Comprehensive crime categorization
- Detailed incident description
- Real-time form validation

### Statistical Analysis
- Real-time crime statistics dashboard
- Crime distribution visualization
- Monthly and total crime tracking
- Interactive data visualization
- Pattern recognition and analysis

### User Interface
- Responsive design for all devices
- Modern and intuitive navigation
- Smooth animations and transitions
- Consistent visual language
- Accessibility considerations

## Getting Started

### Prerequisites
- Modern web browser
- Internet connection
- Google Maps API key

### Installation
1. Clone the repository
2. Add your Google Maps API key to the configuration
3. Open `index.html` in your web browser

## Usage

### Viewing Crime Data
1. Navigate to the home section
2. Use the map to explore crime locations
3. Filter crimes by type or date
4. Click markers for detailed information

### Reporting a Crime
1. Navigate to the Report Crime section
2. Fill in the required information
3. Select location on the map
4. Submit the report

### Viewing Statistics
1. Navigate to the Statistics section
2. View crime distribution
3. Analyze crime patterns
4. Track monthly statistics
